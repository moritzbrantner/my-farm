# Bread Production Moves To Farmhouse Oven

Bread production now starts from an Oven bought as a Farmhouse Upgrade instead of a placed Bakery Structure.

The Farmhouse is the fixed home base for Farm Residents, so early kitchen production belongs there rather than on a movable farmyard tile. Keeping the Oven in the Farmhouse also removes a placement choice that made the first bread loop feel larger than its gameplay role.

The Oven keeps the old Bakery balance: 40 coins, unlock level 2, and queue limit 2. Forward catalog, Farm state, Farm view, Commands, and generated contracts use Farmhouse Upgrade and Oven terminology. Legacy Bakery production remains compatibility context for later migration work, but new purchase flow state is owned Oven state on the Farm.
