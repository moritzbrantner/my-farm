# Triage Labels

Use these canonical role labels exactly:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs reporter information | `needs-info` |
| Ready for agent implementation | `ready-for-agent` |
| Ready for human implementation | `ready-for-human` |
| Will not be worked on | `wontfix` |

PRD issues use `prd`. Agent-loop runtime state uses labels prefixed with `agent-loop:`.
