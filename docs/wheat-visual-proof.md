# First owner review: generated Wheat and Field Plot soil

**Scope:** My Farm #125 Wheat-only playable web slice. Corn, structures, residents,
animals, decoration, shared native presentation and complete effects/audio kits
remain separate consumer work under #125 / #148.

## Previously deployed vs this change

| Phase | Existing Pages (prototype) | Updated Pages (this PR) |
| --- | --- | --- |
| Empty Field Plot | Flat brown box | Tileable generated tilled soil, with PBR normal and roughness textures |
| Wheat just planted | Six cylinders topped by balls | Bounded Blender-authored green Wheat stalks |
| Wheat growing | The same cylinders/balls | Recognizable golden heads, same authored Wheat family |
| Ready Wheat | Larger yellow balls | Golden mature heads and a subtle circular ready indicator |
| Resident Harvest | Command queued, then state changes | Queued command remains visibly ready; actual completed task removes Wheat |
| Silo inventory | Generic letter W | PNG derived from the same approved mature Wheat GLB |
| Save/reload | Browser-local WASM save | Identical authority; appearance rederived from saved timestamps |

Sources: `asset-tooling` at commit `3e436886f8b8039c1b1034f221166f86c97f5c86`,
`examples/wheat/build.ts`, `examples/tilled-soil/build.ts`. The build uses the
pinned Blender release and static asset bundle, checks Wheat's packaged AssetRefs,
and pins each distributed GLB/PNG hash in the shipped `farm-art/manifest.json`.
No generator runs in the browser.

## How to review the actual scene

On the PR, open the GitHub Actions **Validate → Web validation** artifacts and
download `wheat-visual-evidence`. It contains six real Chromium browser captures:

- `01-desktop-early.png`, `02-desktop-mature.png`, `03-desktop-ready.png`
- `04-mobile-ready.png`, `05-desktop-harvested.png`,
  `06-mobile-harvested.png`

Review these against the existing [deployed prototype](https://moritzbrantner.github.io/my-farm/)
**before merging**. The deployed URL updates only after merge and successful
Pages deployment. Captures are generated by `apps/web/tests/wheat-art.spec.ts`
from the genuine WASM runtime; its fixed-time fixture alters only saved
Crop timestamps and uses actual Resident Task execution for harvest/deposit.

Build locally with `bun run build:art` (requires Bun and network access for
**build-time** source acquisition and pinned Blender). Then
`bun run test:wheat`, `bun run build:pages` and
`bun run test:e2e:pages-demo`. `bun run verify:art` checks file integrity
independently of the generator source directory.

**Gate for #148:** evaluate generated soil readability, young-vs-mature Wheat
silhouettes, mobile field size, and icon coherence using the actual captures.
Do not extend style to other asset families before owner acceptance.
